# 針でπ (hari-pi)

**https://hari-de-pi.vercel.app**

板張りの床に爪楊枝をばらまいて真上から撮ると、継ぎ目をまたいだ本数から円周率を推定するWebアプリ(ビュフォンの針)。

- 撮るたびに推定値と **95%区間** が更新され、本数を増やすほど区間が縮むのがグラフで見える
- 区間がまるごと 3.0〜3.3 に収まるまでは「まだπとは言えない」と言い切る。あと何本要るかも出す
- 検出に自信のない爪楊枝は数えず、除外した本数を出す。違っていたらタップで直せる/見落としは両端をタップして足せる
- カメラがなくても「デモで撒く」(合成写真)で一通り試せる

## しくみ

1. 継ぎ目を1か所、となりの継ぎ目を1か所タップ → 間隔 t。向きは勾配の向きの平均で見当をつけ、投影プロファイル(板目に沿って足し合わせた断面)が一番くっきりする角度に詰める。タップ位置も断面の谷(継ぎ目)に吸着
2. Sobel → 非極大抑制 → 板目と平行に近いエッジ(継ぎ目・木目)を捨てる → 向きつき確率的 Hough で線分
3. 平行・近い・極性が逆の2本の縁を対にして爪楊枝の中心線にし、重複・途切れをまとめ、明暗の断面で先端まで伸ばす
4. 長さ l = 数えた爪楊枝の長さの最頻値。交差判定は長さを l にそろえた線分で行う
5. 板目から θ0 = 10° 未満の爪楊枝は木目と区別できないので数えない。その条件付きの交差確率
   `P(π) = ∫_{θ0}^{π/2} min(1, r sinφ) dφ / (π/2 − θ0)`(r = l/t)が観測した割合と一致する π を解く
6. 区間は交差割合の Wilson 区間を π に写したもの。板目・長さの測り誤差は含まない

## 開発

    pnpm install
    pnpm dev    # http://localhost:5830
    pnpm test

計算は `src/lib/` の純粋関数(推定量・区間・交差判定・校正・検出・合成写真)、画面は `src/ui/` と `src/app.js`。
`window.__app` に `runDemo()` / `tapAt(x, y)` / `addShot()` / `estimate()` を出してあり、ヘッドレスでも一通り動かせる。
写真はどこにも送らず、集計(本数だけ)をブラウザの localStorage に保存する。
